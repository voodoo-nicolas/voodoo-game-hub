# IP name audit — 2026-10-06 (Phase 0d)

Every game in `manifest.json` (103), checked against `docs/IP_AUDIT.md`'s
blocklist and principles, plus a scan of each game's code and text for
trademarked names and a spot check of looks that copy a famous original.
**Applied 2026-10-06 (owner approved all):** every "Needs a decision" row
below is done — display names in the manifest and in each game, ids and
stat keys unchanged (IQ Test's "Blitz" stats keep their keys and show
"Speed Round" / "Relámpago" labels; Spanish uses "Relámpago" rather than
"Ronda rápida" because it reads right in every sentence of the IQ data;
Road Hopper is "Saltacarreteras" in Spanish, an existing translation).
Spin the Bottle and Would You Rather were archived with the Drinking Games
instead of being edited. Hangman's COCKTAIL / CHAMPAGNE / CHAMPAN became
COCOA / JUICE / HORCHATA.

Not legal advice, and no trademark database was searched for this pass:
rows marked *verify* need a TMview / INPI / USPTO look before launch.

Risk: **HIGH** = a known trademark is in the name · **MED** = close to a
trademark, or the name is fine but the look copies the original · **LOW** =
generic but used by others · **OK** = generic.
