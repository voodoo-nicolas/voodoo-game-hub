# Web version (iPhone / Safari)

Live: https://voodoo-nicolas.github.io/voodoo-game-hub/play/ (GitHub Pages serves `docs/` from master). `python tools/hub.py web` exports the `Web` preset to `builds/web/`; `--publish` copies it into `docs/play/`; live once that commit is pushed (cache ~10 min). Bundles every game (runs the source it was built from): re-publish after game changes iPhone players should get. No APK/pack version bump.

- **One thread**: no-threads web build (GitHub Pages can't enable SharedArrayBuffer). `Thread.start()` silently never runs; `WorkerThreadPool` tasks run on the spot, blocking. Branch on `OS.has_feature("web")`: Sfx renders one sound per frame, Sudoku generates after drawing "Generating...", Chess CPU thinks in place, Pool/Poker AIs and Trace It's photo-to-lines block briefly, Neon Blast renders effects synchronously the first time (cached in user://). **A new game must not need a `Thread`** or needs the web branch (`hub.py check` fails on `Thread.new()` in a script without `OS.has_feature("web")`).
- **Draw calls**: everything drawn in a `_draw()` is sent to the GPU again every frame, and each `draw_polygon` / `draw_colored_polygon` / `draw_polyline` is its own draw call (and its own buffer). The IQ Test's shaded faces were ~230 each, so "odd one out" (4 faces) was ~930 draw calls a frame (a plain screen ~30-90) and froze a tester's iPhone twice (2026-10-16). Fix: `Art.baked()` in `voodoo_iq_art.gd` paints a static drawing once into a SubViewport (`UPDATE_ONCE`, premultiplied-alpha blend) and shows it as one texture; faces and the brain map use it (926 -> 14, 292 -> 42 calls). Many triangles with per-vertex colours = one `RenderingServer.canvas_item_add_triangle_array`, not a `draw_polygon` each (the face's shaded head went 14 ms -> 0.2 ms). Measure with `Performance.RENDER_TOTAL_DRAW_CALLS_IN_FRAME` under `--rendering-driver opengl3` (the web renderer).
- Name: Godot titles the page with `config/name` ("Voodoo"), so `hub.py web` rewrites `<title>` and adds the iPhone Home Screen name from `Brand.NAME`. Icon = project icon.
- Fonts: browsers can't use phone fonts. `assets/web_fonts/emoji.ttf` (Noto Color Emoji) + `symbols.ttf` (DejaVu Sans), cut to used characters by `hub.py web-fonts <NotoColorEmoji.ttf> <DejaVuSans.ttf>`, attached behind the default font by `scripts/common/web.gd` (from Settings). `hub.py web` warns when code uses a character the fonts lack: rerun `web-fonts` (sources: github.com/googlefonts/noto-emoji `2D/fonts/`, dejavu-fonts releases; `pip install --user fonttools`). Only the Web preset ships them.
- No downloads, no APK update: GitHub release downloads send no CORS headers, so a game the page doesn't bundle shows "Update app" (reloads the page); APK update check skipped. Supabase (auth, PostgREST, Realtime, Edge Functions) and raw.githubusercontent.com allow browsers. Media packs (none yet) need bundling or CORS-friendly hosting.
- Saves live in browser IndexedDB (user://). Safari deletes site storage after ~7 days without a visit; Home Screen web apps are exempt but PWA mode is off (its service worker would cache the build; updates show only on the launch after next).
- `docs/` has a `.gdignore` (else Godot imports `docs/play/*.png` into every export). Not iPhone-tested.
- Size (v0.38.0, 2026-10-16): index.wasm 39.5 MB + index.pck 36.6 MB, both gzipped by Pages (~10 + ~33 MB on the wire); the pck grew from 12 MB with the hub/category/felt/leather art and intro videos. Music: `music_library.gd` downloads nothing on the web (synthesized tracks, rendered a few ms per frame by `music.gd`). The shared sound library (`media/common/sfx/`, 6.1 MB, added 2026-10-24) is in the Web preset whole (all_resources); trim it there if the download gets too big.
- Testing in the Claude browser pane: emulate a phone size that fits the pane (e.g. 320x568). A bigger one gets scaled down and the game then draws into ~3/4 of the canvas -- a test artifact, not a bug. Its clicks are mouse events: games that swipe with `InputEventScreenTouch` (2048) need a JS `TouchEvent` on the canvas to test.
