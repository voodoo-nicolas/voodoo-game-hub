# Trace It / Calcá (`trace_it`) — camera tracing

Hub's first educational game and first camera user. Single player, no scores (`"board": "none"`: kit hides 🏆, posts nothing). Phone propped over paper; back camera shows paper live with the picture on top; player traces in pencil. Built in milestones on branch `trace-it` (worktree `../voodoo-game-hub-trace`, so master pushes can't list it early). Done: Free mode. Next: accuracy check, guide levels, courses + lessons, progress/achievements, Supabase sync, store. **Teaching is the point**: every teaching aid is a player option (step by step, lessons, coaching, fading help). Roadmap `docs/trace-it-roadmap.md`.

- Camera: Godot `CameraServer` (Android Camera2), no plugin (`tools/camera_spike/README`). `trace_it_camera.gd`: bind CameraTextures to the material *after* setting `camera_feed_id`; upright = inverse of `feed_transform` (+ mirror X for FRONT); pick lowest-id back camera at ~1280x720; warn when dark (fps drops to 10). No torch.
- Camera permission in the APK (`permissions/camera=true`, build 34) -> `"min_build": 34`. Runtime `OS.request_permission`; denied -> "Open settings" via `JavaClassWrapper` + `AndroidRuntime`.
- Pictures never leave the phone; an imported photo is kept only as `user://trace_it_free_source.png` for Resume.
- Photo -> lines on CPU (`TraceItArt.line_art`, `WorkerThreadPool`, ~0.6 s): blur to step detail, Sobel, thinning, keep strongest share; "Big shapes" posterizes to 3 tones and traces borders. Accuracy check will reuse the masks. Built-in drawings are data (`trace_it_drawings.json`: strokes tagged by step, own Spanish, kinds incl. arc/spiral/golden_spiral/dots, "w" thin guides) grouped into **studies**. Looks: photo/gray/lines/invert/hatch/dots (shader sized to the picture); guides: grid, golden lines, golden spiral (`TraceItEngine.golden_layout`).
- Overlay size fixed when a picture loads (only pinch changes it), only the first two fingers move it; 📷 cycles cameras (autofocus "breathes", Godot can't lock focus; a wide fixed-focus lens doesn't).
- **Dev build on a phone**: preset `TraceDev` (package `com.viral.voodoo.dev`, arm64, every other game excluded, feature `trace_dev` main-scene override) installs beside the real app. Release template signed with the shared *debug* key (never the real one), ~29 MiB (< Remote Control's 30 MiB limit): `GODOT_ANDROID_KEYSTORE_RELEASE_PATH=<Keystore>/debug.keystore GODOT_ANDROID_KEYSTORE_RELEASE_USER=androiddebugkey GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=android godot --headless --path . --export-release TraceDev <abs>/builds/trace_dev.apk`. Its exclude list names each other game: regenerate when games are added (an include filter can't re-add a folder the exclude drops).
- Tests: logic in a throwaway test (pinch keeps both fingers' points, lock, save round trip, every drawing in bounds); screens with `tools/shot.gd`.
