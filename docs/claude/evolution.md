# Evolution (game notes)

Endless pond, landscape, missions + evolution tree. Files in `scripts/games/evolution/`: `evolution_engine.gd` (rules, TUNING), `evolution_data.gd` (species, tree, abilities), `evolution_art.gd` (all drawing), `evolution_controls.gd` (stick + ability buttons, Last Shift layout), `evolution_screens.gd` (creature + tree screens), `evolution_game.gd` (HUD, vision overlay shader). Test: `tools/test_evolution.gd`.

- World: `y = 0` is the water surface (the only wall); sides and depth are endless. Spawns come in a ring just outside the player's view and recycle behind.
- Progression (owner 2026-10-24): blind blob (jolts) -> eat creature value `tail_value` 5 (or one creature that has a tail) = tail -> value `eye_value` 12 (or one with an eye) = eye, all while still size 1 (xp is capped just below size 2 until the eye opens) -> the eye opens the evolution tree with `Data.TREE_DNA` 2 (owner 2026-10-30, halfway to size 2 with no DNA: "at least 2 or 3 points I'd have already"; before, "Grow to size 2" opened it (`tree_size`, now unused), and before that 10 kills after the eye, which came at size 4-5) -> missions give DNA. The first rare creature that comes within half a screen (`half_screen`, set by the game) gives the mission "Investigate that strange creature" (+1 DNA; owner 2026-10-30, so a new player knows it is special); later rares give "Catch: ..." missions. The tail/eye carrier cells only spawn while you are size 1. Missions are discovered (new species, the surface, depth marks), show a bar only (no counts, no rewards). "Stay alive near a hunter" is the Close call badge, not a mission.
- Size levels (`Data.LEVELS`): the smallest dots = level 1 = value 1; a creature is worth its level; 3+ levels below you = worth nothing + faint particle, 4+ = invisible. Speed grows with size (`size_boost`) so it never feels slower on screen.
- Growing: you grow by **xp** (`engine.xp`; a creature = its level in xp, a food speck `food_xp` 0.5); your mass follows (`mass_of_xp`: straight line from one size's start mass in `LEVELS` to the next). Owner 2026-10-29 (phase 2 of the rework, see below): each size costs `Data.XP_KILLS` kills of prey one size below (owner 2026-10-30 "bring down xp requirements 25%": every size x 0.75, now 390, 862.5, 660, 697.5, 615, 1425, 1725, 2250, 6000 = 14,625 kills to size 10, 88,350 xp; before 520, 1150, 880, 930, 820, 1900, 2300, 3000, 8000 = 19,500 kills, 117,800 xp; DNA per size did not change, so DNA comes a third faster per kill; owner 2026-10-29 wants size 2 at ~10 min, size 3 +20, size 4 +30, ...), so `xp_span` = kills x (size - 1) (at size 1 x 1): 520, 1150, 1760, 2790, 3280, 9500, 13800, 21000, 64000 = 117,800 xp. Past size 10 each span is 1.3 x the last (the size shown stays 10). Creatures your own size are worth more, so real runs are a bit quicker than the table. History: owner 2026-10-23 "slow down the growing, speed up the mutations"; 2026-10-24 `xp_first` 30, `xp_second` 50 (the owner's "X"), then x1.5 (~500 kills; it was 5 then x2). Code that sets `player.mass` directly (tests) is re-synced (`_sync_mass`). The gold bar = progress to the next size. Size missions give only 0.5% of the current size's xp (`story_xp`; it does not feed the 🧬 bar; at 40% a greedy bot hit size 5 in 84 s: missions were the main shortcut, owner 2026-10-29 "size 5 in 5 minutes, too easy too fast"). Food specks give `food_xp` / size (0.5 at size 1, 0.1 at size 5), Photosynthesis a slow xp drip. `STAGES` start at sizes 1, 2, 3, 4, 6, 8.
- DNA (owner 2026-10-29: "never more than 1 or 2 dna points at a time, except when eating rare creatures"; "52 dna lands all at once... seems VERY wrong"): no DNA for reaching a size (event `level`, banner "Size N!"). The eye opens the tree with `Data.TREE_DNA` 2. Then the green 🧬 bar under the XP bar (`dna_bar`, `dna_frac`) fills with what you eat (`_gain_xp(.., feeds_dna)` -> `_fill_dna`, rate `dna_rate` = `Data.DNA_PER_SIZE` spread over the size's xp): a full bar = +1 DNA (event `dna_tick`: green sparkle + soft chime, no banner), never more than 1 per meal. `DNA_PER_SIZE` 4, 12, 16, 20, 24, 28, 30, 32, 34 = 200 by size 10 (size 1 was 0 while the tree waited for size 2) (about 1 point every 3 kills at size 2, every 10 at size 9); missions +1 and rare creatures +2 to +8 on top (~230); past size 10 one point per `DNA_PAST_10_KILLS` 10 kills. The tree still costs 262 (phase 4 makes it 300+ with forks so no run gets everything). History: `LEVEL_DNA` paid each size at once (52 at size 2, all 262 by size 10; owner 2026-10-24 "size N of 10 = N/10 of the tree").
- Rework plan (owner 2026-10-29, one pack update per phase): 1 speed + swimming (pack v11), 2 growth table + 🧬 bar (this), 3 water colour by depth + ocean zones + creatures by depth, 4 tree ~450 DNA with exclusive forks (body plan at size 3; Acid spit or a Harpoon tentacle that grabs and reels prey in; ...), 5 body shapes from the tree (fish/marlin, squid/octopus, crab, jelly, eel), 6 bosses + boss achievements. Before phase 4 ask the owner: the body plans, whether forks are final (or undone by molting).
- Food specks are always there and always edible at every size (they used to vanish 3 sizes below you, i.e. at size 4); drawn a little fainter once they are far smaller than you; always `food_xp` 0.5.
- What lives where, by YOUR size (`Data.SPECIES`; owner 2026-10-24: 1-3 bacteria, 3-6 fish, 5-10 all sorts, 9-10 sea monsters): `until` = the biggest player size that still meets the species (cells, viruses and the swimmer 3); `tier` = from which size it appears. Size 3 adds Guppy and Perch; jellyfish and Squid from 5, Reef octopus 6 (it took the Kraken's old place), Beluga and Orca 7; sea monsters Leviathan, Kraken (moved from 6), Sea wyrm, Titan turtle at 9, Sea serpent and Abyss maw at 10 (the test wants 20%+ monsters at 9-10). From size 4 only animals spawn: fish, jellyfish, squid, rays, snakes, octopus, turtle (`shape` fish / jelly / squid / ray / snake / octopus / turtle, body plan in the species' `fish` dict, drawn by `Art._fish` etc.; the bigger the creature the more parts: pelvic fins 5+, glow dots 6+, barbels and tail streamers 7+). Toxic and rare creatures are sized relative to you, so each has an `adv` animal form (name, shape, plan) used once it is size 3+ (gut worm -> venom snake, toxic spore -> spiny pufferfish ...). Cell parts (nucleus, vacuoles, the player's bean mitochondrion and hair fringe) show only while you are size 1-2 (`detail` in `Art.draw_creature`, `cell` 0..1 in `Art.draw_player`, faded size 2 -> 3 by `_cell_fade`).
- Species are hostile to each other once the eye is open (`_social`, `_npcs_eat_each_other`); creatures spawn spread out (`_ring_pos_sep`).
- The info screen, tree and "you unlocked ..." pop-ups pause the tree (`get_tree().paused`).
- Blue power bar: actives (`Data.ABILITIES`) spend it, it refills slowly. More points in an active make it cheaper, longer, stronger.
- Evolution tree = a graph (`Data.NODES`): creature at far left, 4 branches (Offense, Senses, Movement, Defense; Tentacles sit inside Offense behind the "Tentacles" node). Each node has `max` points, several `req` prerequisites, and can open several nodes. Locked nodes show "?". Screen: `evolution_tree_view.gd` (drag to pan, tap to select).
- Ability buttons (right thumb, max 4, none at the start): 1 = offensive, 2 = defensive (auto-assigned, the player picks which on the creature screen), 3 and 4 arrive at growth stages Hunter / Predator and take either kind. Rules in the engine: `slot_visible`, `eligible`, `auto_assign`, `cycle_slot`, `use_slot`.
- Vision rings = `Data.SIGHT_FRAC` of screen height; blur by lens points (`Data.BLUR`).
- Toxic creatures appear from size `toxic_from` 3, with the first hunters (owner 2026-10-30: slow healing or glow meant nothing while nothing could hurt or chase you), and eating one costs `toxic_bite` 5% of your max health (never the last point) on top of its ailment. 4 kinds, each with a fixed `ailment` in `Data.SPECIES` (Toxic spore = brittle, Glow spore = glow, Gut worm = appetite, Mold spore = slow healing). HUD shows each ailment with a timer bar (`ail_full` = its starting length).
- Resistances (`Data.RESISTS`, owner 2026-10-20): getting the same ailment `Data.RESIST_AT` = 10/30/50/70/90 times gives the opposite trait 1/5..5/5 for free; each rank cuts the ailment's time by 20%, 5/5 = immune. Counted per run (`ail_count`), shown on the creature screen.
- Chasers: only the nearest `Data.DIFFICULTY.chasers` (2/3/4) hunters chase you; no new hunters spawn while `threat_cap()` that can eat you are around: 1 at size 3 (the first predators), +1 per size, up to `hunter_max` (4/6/8). Hunters spawn at least `hunter_gap` (10 s) apart (owner 2026-10-22: 5+ chasers early on was impossible to evade).
- Rare (golden) creatures: gold glow, sparkles and ripples (`Art.draw_ripples`); faint ripples also show just past your sight. Rare and toxic creatures are always visible and worth eating (they used to be sized 3 levels below you = invisible). Owner 2026-10-24 "make them rare": a family picked by `_pick_rare` (still `rare_chance` 1.2% of spawns), each with `tier` (your size), `weight` and extra `dna`: Golden spore/fish (1+, w6), Starfish (3+, w4, +2), Seahorse (3+, w3, +3), Mermaid (5+, w1.5, +5), Little Poseidon with a trident (7+, w0.6, +8; event `rare_dna`). Shapes `star`, `seahorse`, `mermaid`, `poseidon` (`Art._star`, `_seahorse`, `_merfolk`); merfolk skin and hair vary by seed. All count as "Rare eaten" and for the rare mission.
- Eating a creature plays `chomp`, `slurp` or `munch` (synthesized in `evolution_sound.gd`, never the same twice running; owner 2026-10-30 "a variation of 2 or 3 sounds, not the current one"). `eat` / `gulp` stay in the file, unused. The shared library has no eating recordings.
- Music (owner 2026-10-24 "there's no music"): shared `Music` autoload through `_play_music()` in the game: calm track 0 while you are small, lively track 1 from size 6 (`MUSIC_LIVELY_AT`), switched on each size-up and new run.
- Surface: pushing up into it slides you along at full speed (it used to catch).
- Water (from the eye on): `TUNING.units_per_m` = 50 world units per metre of depth (it was 10: 320 m was a few centimetres of screen; the stats' Distance swum still counts 10 units = 1 m for the badges). The water colour darkens with depth (`_water_col`), an `env_warn` banner comes 15% of your limit / 3 °C before the cold or pressure hurts. Temperature `temp_at()` falls with depth (24 °C surface to 4 °C) and in cold currents sideways; limits `min_temp()` / `max_depth_m()` (8 °C / 200 m bare). Too cold = slower + hp loss, too deep = hp loss, no regen; death cause shown. HUD left: depth + temperature with your limits. Habitat branch: Antifreeze, Pressure cells, Fat layer, Deep-sea body, Abyss dweller.
- Endless mode (owner 2026-10-22; setup screen, "When you die": Game over / Endless, pref `endless`): dying calls `engine.revive()` instead of ending the run: back at the start of your size (never below your growth stage), full health, out of the deep water, nearby hunters removed, `revive_grace` 5 s of safety; traits, DNA, eye, tail and missions stay. Shown with a "You died" pop-up. Endless runs never reach the end dialog, so they do not set "Best score" / "Games played" (stats like biggest size and distance still count).
- Colours: the "Choose your creature" screen (`_open_creature`) opens by itself before the first run (Quick Play skips the setup screen, so `prefs.picked` gates it) and from the Landing's "🎨 Your creature" under More.
- Look: creatures are drawn smaller and the camera is zoomed out a little (`radius_k` 6, `cam_base` 0.88; owner 2026-10-22). The start blur is circular AND radial: `OVERLAY_SHADER` samples toward the centre (`radial`, streaks bursting out from you) plus a disc blur, both stronger toward the edge of sight. Joystick `STICK_R` 97.5 (25% smaller than 130).
- Cold deaths: the water is colder with depth AND in sideways cold currents (up to 7 °C), so 90 m can already be too cold for a bare cell. The HUD line turns amber near a limit, the screen takes an icy tint, and the death text gives depth, temperature and limit.
- Tree: "?" only for `locked` nodes; `stage` nodes (prerequisites owned, too small) are readable but not buyable.
- Speed (owner 2026-10-29 "game feels slow/laggy", "swimming needs to be fast, agile"): measured on an Intel UHD 600 PC (about a mid-range phone), 1600x720: 10 / 12 / 7 / 4 fps at sizes 1 / 3 / 6 / 9 before, 28 / 35 / 30 / 30 after. Causes and fixes: (1) in Godot 4.7 every `draw_circle` / `draw_arc` / `draw_polyline` / `draw_colored_polygon` costs 60-110 µs (its own GPU buffer); the game made 1,000+ a frame. `Art.disc` (white disc texture), `Art.arc` / `Art.strip` (one `draw_multiline`, antialiased only for solid colours: see-through joints showed dots) replace them everywhere; `draw_colored_polygon` (bodies, fins) is still used. (2) The water's light blobs and plankton were ~1,500 GDScript circles: now one MultiMesh of quads that `WATER_SHADER` places on the visible grid cells (`_update_water`, `WATER_LAYERS` must match the shader's CS / PAR). (3) The vision blur reads 15 screen samples instead of 35 (from mip levels; `lod_ok` 0 on the web) and 1 outside your sight; `DARK_SHADER` (no screen copy) once your eyes are sharp. (4) `_social` / `_npcs_eat_each_other` compare every pair from packed arrays made once a step (`_snapshot_npcs`): engine step 8.9 -> 2.8 ms with 40 creatures. (5) A slow frame runs up to 3 engine steps (it used to cap delta at 0.05 s: slow motion under 20 fps). Still GPU-bound on that PC (~23-28 ms): the blur's screen copy is the biggest part; dropping its mipmaps saves ~4 ms but makes the blur grainier (not done).
- Swimming (owner 2026-10-29): `MOVE_MULT` starts at 0.8 with the first tail (was 0.55; top 1.15 unchanged; hunters and fleeing prey scale with your top speed), `player_accel` 13 (creatures keep `accel` 7), the body turns faster (16), the tail beats faster and wider with speed, and a wake of bubbles trails you above 45% of top speed (`_wake`). No camera lead (the vision ring, overlay and controls assume you are at the centre).

## DNA tree editor (2026-10-30)
`python tools/dna_editor.py export` builds `tools/dna_editor/dna_editor.html` (open in a browser, not committed): drag traits, edit rank/cost/stage/prerequisites/body plans, add or delete traits, live checks (loops, rank > max, overlaps, stage order). Download `tree.json`, then `python tools/dna_editor.py apply tree.json [--dry-run]` rewrites `NODES` / `NODE_PLANS` in `evolution_data.gd`. Ids are never renamed; deleted traits are commented out (and refused while other scripts use the id); new traits are inert until the engine gives them an effect; new names/descriptions need `es.json`. `roundtrip` proves parse + format reproduces the file. A prerequisite the body plan can't have is skipped by the engine (`reqs_met`), so that is not flagged as an error. `docs/claude/evolution-dna-tree.svg` is a static picture of the tree.

## Tree redesign (owner 2026-10-30, designed in the DNA tree editor)
- 59 traits (Pufferfish deleted: commented out in `NODES`). Plans are nodes inside the branches now: Marlin (needs Fins), Lionfish (Tough membrane + Warning colors), Crab (Regeneration), Squid (Strong jaws), Eel (Acid spit). Everything after a plan needs that plan (Eel: Electric shock; Squid: Tentacles > Stinger / Suction > Grab; Lionfish: Shell > Poison skin > Spikes > Spine burst; Crab: Left + Right claw arm > Decoy clone > Drop a limb; Marlin: Cilia coat > Streamlined body > Speed boost).
- **Choosing a plan closes the others and whatever comes after them**: the rival plan nodes stay on the tree greyed ("closed"), every trait that needs one (directly or further up) is hidden (`node_hidden` > `_behind_closed_plan`). `NODE_PLANS` is empty (the tree decides); the old "pick a plan first" state can no longer happen. A rare creature never grants a plan or a hidden trait.
- **No body plan before size 5**: node key `"size": 5` (min size; `node_state` returns "stage", the tree says "Grow to size 5 to evolve it."). Plan nodes are also stage 3; traits behind a plan are stage 3 (stage 4 three steps below a plan), `stage` is never below a prerequisite's.
- Growth is one trait per size: `growth` (size 3, 5 DNA) then `growth_4` ... `growth_10` (6, 7, 8, 9, 10, 11, 12) = 68 DNA; `size_cap` = 2 + how many you own. Growth size 3 to 10 each need the one before.
- New traits with effects: Left / Right claw arm (`claw_step` 0.03 each lower the eat ratio, on top of Strong jaws; Decoy clone needs both), Speed boost (`rush`, active, 50 power, 4 s, `rush_mult` 1.6 on top of the dash). NOT built: Speed boost does not kill what it touches (the owner's first wording), the claws have no animation or grab of their own, Eel only has Electric shock behind it.
- Pack/app: `size` is read with `n.get("size", 0)`, so an older pack is unaffected; this is a pack change only (tree + engine are in the pack).
