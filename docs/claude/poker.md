# Poker (`video_poker`, pack v9 live)

**Revamp in progress (since 2026-10-27, unpublished on master): decisions, phases and status in `docs/claude/poker-revamp.md`. Read it first.**

Texas Hold'em, Omaha, Five Card Draw, Seven Card Stud (Stud Limit only), and since the revamp Short Deck, Pineapple, Crazy Pineapple, Omaha Hi-Lo (No limit / Pot limit / Limit); vs computer (cash tables at 3 stakes, free tournaments), pass-and-play 2-6, online heads-up, Video Poker as a mode, 🎓 Training. **Id stays `video_poker`** (stats/board carry over; board "Most chips").

- Files: `_eval.gd` (hand score = one int, bigger wins; `score5` fast path for Omaha), `_table.gd` (pure engine; JSON-safe `to_dict` = save AND online state; side pots from each seat's `total`), `_ai.gd` (Monte Carlo win chance + pot odds; computer players and coach on `WorkerThreadPool`, keyed by `_decision_key()` so stale answers drop), `_view.gd` (draws table; viewer's seat always at bottom), `_machine.gd` (Video Poker screen), `_training.gd` + `_drills.gd`, `_engine.gd` (Video Poker logic + Jacks or Better hint), `_game.gd` (modes, chips, saves, online).
- Chips in `user://video_poker_chips.json` (with Home picks), shared by cash tables and Video Poker. A seated cash stack is in the table save, NOT in chips; `_discard_save()` pays it back before any New… deletes the save. Video Poker saves its hand in `user://video_poker_machine.json` (never clobbers a table save).
- Online: host = seat 0 and deals every hand (shuffled deck in state); each move sends the whole table. `_hand_over()` must not change shared state online (no elimination bookkeeping) or every hand triggers a resync. Test: `video_poker` driver in `tools/test_online_pair.gd`.
- Friends tables (phase 5, apps v0.39+): `net` = whichever online layer is in use (`online` = OnlineMatch heads-up, `table_net` = OnlineTable 2-6); seat kind = player number. Details in `poker-revamp.md` (Phase 5). Test: `tools/test_online_table.gd`.
- Hand history: `_history.gd` writes one JSON line per hand to `user://video_poker_history.jsonl` (last 1000 kept; format in the file's header). It **watches** the table: `_game.gd._after_change()` calls `history.observe(...)` after every change, so host, guest and a resumed save all record the same hand and the table state/online messages don't grow. The hand in progress rides in the table save (`"hist"`); `history.abandon()` wherever a new table starts. Test: `tools/test_poker_history.gd`.
- Variants: `_table.gd` is the shared engine; `_rules_<variant>.gd` (base `_rules.gd`) answer what differs (cards, deal, streets, deck, scoring, AI traits). The computer players and coach (`_ai.gd`) never name a variant: they ask `t.rules()`. Tests (fingerprints pin behaviour): `tools/test_poker_rules.gd`, `tools/test_poker_ai.gd`.
- Coach follows the Starting hands drill's Chen tiers preflop in Hold'em, win chance vs pot odds after, so advice and drills agree.
- i18n: poker's check uses key `"Check "` (trailing space, `View.CHECK`) -> "Pasar".
- Web: AIs block briefly (no threads).
- Options (since the revamp): four-colour deck, chip piles vs numbers, win chance; stored in `prefs` of `video_poker_chips.json`. Win chance and the coach both mark hands `aids` in the history.
- Stats, replay, XP (phase 2): `_profile.gd`, `_stats.gd`, `_replay.gd`, `_replay_screen.gd`, `_stats_screen.gd`; details in `poker-revamp.md` (Phase 2). `History.observe()` returns the hand it finished; the game feeds the profile from it.
- **Menus (2026-11-17, owner: "select the poker first, then each one has its own menu")**: the Landing (kit stack) shows "Choose your game" = a felt tile per variant (its cards fanned) + wide Video Poker / Training tiles, inserted by `_game.gd._install_picker()` right under Resume / Quick Play; the kit's Single player / Multiplayer buttons are hidden (modes stay in cfg for the kit's Quick Play and invites; the kit itself is unchanged, it is synced). A tile opens `_menu.gd` for that game: 🏠 Home, chips, the game's hand, record (hands, net, Career stars), betting row, ▶ Quick game (cash table, last stakes/opponents, no sheet), tiles Career / Cash / Tournaments / My stats (filtered to the game) / Pass and play / Friends table / Online. Sheets, Career and Stats go back to that menu (`menu_variant`, `_back_to_menu()`); Landing > More > 📈 My stats = all games. Android back on the menu opens the pause menu (same as Career/Stats before).
- **Look (2026-11-17)**: `_fx.gd` = the room background (table art + drift + light + vignette + dust) for the table, menus, Career, Stats; `pop_in`, `press` (buttons squash), `win_glow` + `bump` when you win a pot. Obeys ✨ Effects Reduced (`user://fx.json`). STANDARDS §9 exception.
- Characters, tournament formats and Career (phase 3): `_characters.gd`, `_career.gd`, `_career_screen.gd`; AI reads a character's traits by seat name; details in `poker-revamp.md` (Phase 3). Since 2026-11-17 Career is **one ladder per game** (25 stages, 3-4 each; `Career.ladder(v)`, `previous(i)`; a stage starred on the old single ladder stays open; 12 bosses incl. Lady Six, Old Thorn, Mister Twitch, The Twin Masks).
- New variants (phase 4): rules files `_rules_short/pineapple/crazy/omahahilo.gd`, evals `_eval_short.gd` / `_eval_low.gd`; the table's discard phase and split pots are generic (rules answer `discard_kind`, `is_split`...). See `poker-revamp.md` (Phase 4).
